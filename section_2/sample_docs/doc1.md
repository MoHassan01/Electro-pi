# Electro Pi AI Engineer Test Overview

The Electro Pi AI Engineer Technical Test evaluates practical skills in building AI applications.
It is divided into 4 main sections:
1. LiveKit Agents
2. LangChain (RAG)
3. Quantization
4. Model Deployment

The test gives candidates 5-7 days to complete it. The submission should include a GitHub repo containing the code, README, and write-ups.
The suggested bar for an on-site interview invite is 65+ points.
